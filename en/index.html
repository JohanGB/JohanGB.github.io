How I work

The same four steps in every project, so anyone can reproduce the result.

  1. Fingerprinted source

    Every value points to its file, sheet, row or line and its SHA-256 fingerprint. If a raw file changes, the pipeline stops.

    Where to see it: NowMarket, Factura Viva

  2. Assumptions as data

    Tax, labor and category rules live in versioned files with source, validity and verification status. Nothing legal is hard-coded.

    Where to see it: Nómina Clara, Factura Viva

  3. Validation fixed before looking

    The protocol is written before seeing the test: leak-free rolling origin, a single held-out test and measurement points that never enter training.

    Where to see it: NowMarket, Gaze tracker

  4. Better to abstain than to be wrong

    Whatever does not reconcile goes to review instead of being guessed, and every project publishes its limitations and automated tests anyone can rerun.

    Where to see it: All seven projects

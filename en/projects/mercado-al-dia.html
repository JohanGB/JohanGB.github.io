01Problem

It answers what is cheap this month, in which months each product usually rises and what it will cost in 1, 2 and 3 months, using wholesale prices for Bogotá and the Savannah with Corabastos as reference.

02Data

  • DANE SIPSA monthly wholesale price and supply series and NOAA CPC's ONI (El Niño) index.
  • Raw data is not redistributed: the script downloads it and records its SHA-256 fingerprint. Each price cites the file, sheet and row of the DANE spreadsheet.

03Method

  • Seasonal profile with a 2×12 moving average on log prices.
  • Calibrated naive at 1, 2 and 3 months, with 80 % intervals from conformal calibration (CQR). LightGBM improved on validation but did not pass the deployment rule at 1 month (90 % CI [−0.7 %; +8.6 %]).
  • SARIMAX with the ONI index gave no significant gain over naive; N-BEATS lost on every horizon.

04Validation

  • Protocol fixed before seeing the test: leak-free rolling origin, selection on validation (2021-11 to 2023-10), a deployment rule with a 90 % block-bootstrap CI, and a test on 2023-11 to 2026-09. An independent audit found method errors (D-030); they were fixed and the test was rerun once, so it can no longer be used to decide again.
  • Test results (version 1.1.0): calibrated naive on all three horizons; 1 month, typical error 9.7 % and coverage 80.6 %; 2 months, 16.0 % and 82.8 %; 3 months, 20.2 % and 82.3 %.
  • The "usually goes up/down" advice is right 78.2 % of the time vs. a 73.7 % baseline.
  • 72 automated tests that run offline. With JAX installed, 71 pass and 1 is a documented expected failure; on Windows, where CI does not install JAX, 3 N-BEATS tests are skipped and 68 pass.

05Limitations

  • SIPSA measures wholesale prices at the central market. Retail prices are higher; the tool anticipates rises, drops and seasons, not the exact shop price.
  • Not financial advice.
